\begin{abstract}
Prefill and Decode share accelerator capacity but pressure different latency
objectives: Prefill determines time to first token (TTFT), whereas Decode
determines time per output token (TPOT). Chunked prefill bounds work in one
iteration, but a mixed batch leaves cross-iteration phase allocation implicit.
We present PD-TDM, a phase-level temporal allocator for a single
tensor-parallel replica. A slow SLO-pressure loop updates a Prefill tendency,
and a token bucket realizes it as bounded Prefill-only or Decode-only
iterations. On Qwen3-8B with two Ascend 910B3 NPUs, the evaluated configuration
improves strict joint-SLO attainment by 33.7 and 73.8 percentage points at
conversation and code burst loads relative to native vLLM-Ascend chunked
prefill under the tested budgets. A fixed-ratio MaaS replay shows lower TTFT,
while exploratory Decode-heavy workloads expose an operating boundary. Results
characterize the pinned integrated stack; controller-only gains and an inherent
phase-pure speed advantage are not claimed.
\end{abstract}
